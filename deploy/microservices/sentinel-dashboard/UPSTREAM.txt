Initialize each required <app>.flow.json, <app>.degrade.json, <app>.gw-flow.json, and <app>.gw-api-group.json with a valid JSON array in the configured namespace/group. Missing or invalid data is not implicitly cleared.

The official index loads dist/js/app.js. The build constructs that bundle from the tracked interceptor module and pinned upstream services; native-rule-requests.js checks that they remain synchronized.
Default Dashboard port is 18091 in the default Spring profile; override with DASHBOARD_PORT (or server.port for another profile).
